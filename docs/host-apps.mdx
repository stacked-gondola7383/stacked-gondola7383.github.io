# Calling scripts from your app

The flow is the same on every platform:

1. Create a VM with limits (memory, and optionally the public keys you trust).
2. Optionally register host functions and a key provider.
3. `load` the bytecode. It is verified first; top-level code runs once.
4. Set an instruction budget and `call` an exported function.

<Tabs groupId="host">
<TabItem value="c" label="C / C++" default>

```c
#include "e7/e7.h"

e7_config cfg;
e7_config_init(&cfg);
cfg.memory_limit = 32u << 20;
/* optional: only run modules signed by your key
   cfg.require_signature = 1; cfg.trusted_keys = pub; cfg.num_trusted_keys = 1; */
e7_vm* vm = e7_vm_new(&cfg);

e7_module* mod;
if (e7_load(vm, code, len, &mod) != E7_OK) { puts(e7_last_error(vm)); return 1; }

e7_value args[2];
args[0].type = E7_STRING; args[0].v.str.ptr = "amount=100&currency=CNY"; args[0].v.str.len = 23;
args[1].type = E7_STRING; args[1].v.str.ptr = "s3cr3t";                  args[1].v.str.len = 6;
e7_value ret;
e7_set_budget(vm, 10000000);          /* stop runaway scripts */
if (e7_call(vm, mod, "sign", args, 2, &ret) == E7_OK)
  printf("%.*s\n", (int)ret.v.str.len, ret.v.str.ptr);
e7_vm_free(vm);
```

Link `libe7vm_static.a`, `libe7_bearssl.a` and `libe7_monocypher.a` (on Windows the `.lib`
files plus `advapi32.lib`). Complete example:
[`examples/embed/host.c`](https://github.com/e7lang/e7/blob/main/examples/embed/host.c).

</TabItem>
<TabItem value="kotlin" label="Android (Kotlin)">

```kotlin
import org.e7vm.*

val config = E7VM.Config().memoryLimit(32L shl 20)
    // optional: .requireSignature(SERVER_PUBLIC_KEY)
val vm = E7VM(config)
vm.setKeyProvider { id -> keyStoreDecrypt(id) }          // returns a ByteArray
vm.registerNative("deviceId", ">s") { _ -> Settings.Secure.getString(cr, ANDROID_ID) }
val module = vm.load(bytesFromServer)                      // throws E7Exception if verification fails
vm.setBudget(10_000_000)
val sig = vm.call(module, "sign", "a=1&b=2", KeyHandle(1)) as String
vm.close()
```

Add the dependency `implementation("org.e7vm:e7vm-android:1.0.1")` (desktop JVMs: `org.e7vm:e7vm:1.0.1`, with
JNI libraries for Linux, macOS and Windows inside). The `.aar` and `.jar` are also attached to every
[release](https://github.com/e7lang/e7/releases/latest); see the [embedding guide](reference/EMBEDDING.md) for the repository setup.

</TabItem>
<TabItem value="swift" label="iOS / macOS (Swift)">

```swift
// trustedKeys is optional; when given, only modules signed by those keys load
let vm = try E7VM(memoryLimit: 32 << 20, trustedKeys: [serverPublicKey])
vm.keyProvider = { id in Keychain.key(for: id) }
try vm.registerNative("deviceId", signature: ">s") { _ in .string(UIDevice.current.identifierForVendor!.uuidString) }
let module = try vm.load(bytecode)
vm.setBudget(10_000_000)
if case let .string(sig) = try vm.call(module, "sign", .string("a=1&b=2"), .handle(KeyHandle(1))) { print(sig) }
```

Add the Swift package `.package(url: "https://github.com/e7lang/e7.git", from: "1.0.1")` and depend on
`.product(name: "E7VM", package: "e7")` (or build an XCFramework with `platform/ios/build_xcframework.sh`).
e7vm uses no JIT and allocates no executable memory, which keeps it within the App Store rules for interpreted code.

</TabItem>
<TabItem value="csharp" label=".NET (C#)">

```csharp
// trustedKeys is optional; when given, only modules signed by those keys load
using var vm = new E7.E7VM(memoryLimit: 32 << 20);
vm.SetKeyProvider(id => ProtectedData.Unprotect(LoadBlob(id), null, DataProtectionScope.CurrentUser));
var module = vm.Load(File.ReadAllBytes("app.e7b"));
vm.SetBudget(10_000_000);
var sig = (string)vm.Call(module, "sign", "a=1&b=2", new E7.KeyHandle(1));
```

`dotnet add package E7VM` (native libraries for Windows x64, Linux x64/arm64 and macOS included; the
`.nupkg` is also attached to every [release](https://github.com/e7lang/e7/releases/latest)).

</TabItem>

## Values that cross the boundary

| E7 type | C (`e7_type`) | Kotlin / Java | Swift (`E7Value`) | C# |
|---|---|---|---|---|
| `number` | `E7_NUMBER` | `Double` | `.number` | `double` |
| `boolean` | `E7_BOOL` | `Boolean` | `.bool` | `bool` |
| `i8`…`i64` | `E7_INT` | `Long` | `.int` | `long` |
| `u8`…`u64` | `E7_UINT` | `Long` | `.uint` | `ulong` |
| `string` | `E7_STRING` (UTF-8) | `String` | `.string` | `string` |
| `Uint8Array` | `E7_BYTES` | `ByteArray` | `.bytes` | `byte[]` |
| `KeyHandle` | `E7_HANDLE` | `KeyHandle` | `.handle` | `KeyHandle` |
| `null` / `void` | `E7_NULL` / `E7_VOID` | `null` | `.void` | `null` |

## Keeping secrets in the host

Pass a `KeyHandle` instead of key bytes. When the script calls `hmac(..., key, ...)` the VM
asks your key provider for the bytes, uses them natively, and never exposes them to the
script. Store the keys in the Android Keystore, the iOS Keychain or DPAPI.

## Limits

| Limit | Set with | Default |
|---|---|---|
| Heap memory | `memory_limit` | 256 MiB |
| Instructions per call | `e7_set_budget` | unlimited |
| Call depth | `max_frames` | 20 000 |
| Register stack | `stack_slots` | 262 144 slots |

With `suspend_on_budget`, an exhausted budget suspends the script instead of failing it, so
long work can be spread over several frames with `e7_resume`.

The [embedding guide](reference/EMBEDDING.md) covers every API, the threading rules and the
signing workflow in detail.
