# Viraj Bhalala - Personal Portfolio

A static, GitHub Pages-ready portfolio for Viraj Bhalala, Software Engineer.

## Files

- `index.html` - portfolio structure/content
- `style.css` - responsive design
- `script.js` - mobile navigation and reveal animations
- `assets/` - place your images/resume here

## Run locally

Open `index.html` in a browser.

## Deploy on GitHub Pages

1. Create a repository named `YOUR_USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. Your site will be available at `https://YOUR_USERNAME.github.io/`.

## Important customization

Before publishing, replace:

- `your.email@example.com`
- GitHub URL
- LinkedIn URL
- Project descriptions with your real public projects
- Experience details if any dates/descriptions need correction

Do not publish confidential client/company information.
